# NETWORK SECURITY ANALYZER
A python-based tool designed to analyze network traffic capture files (.pcap).
This script extracts valuable information such as top ports, URLs, and detects traffic on risky ports.
## FEATURES
* Packet Analysis using Scapy library.
* Top Ports Extractions.
* URL Extraction from HTTP traffic.
* Security warnings for dangerous ports.
* Clean output using Pandas.
## TECHNOLOGIES USED
* Python 3
* Scapy
* Pandas
## HOW TO USE

1- Install libraries:
   pip install scapy pandas

2- Run the script:
   python network_security_analyzer.py
